
# GlowUp — Beauty & Skincare Store

A modern skincare e-commerce homepage built using HTML and CSS, featuring product cards, a promotional banner, and a responsive layout.

## Technologies Used
- HTML5
- CSS3

## CSS Concepts Covered
- CSS Grid and Flexbox
- CSS Variables
- Positioning: Relative, Absolute, Sticky
- Hover Effects and Transitions
- Transform and Image Scaling
- Object-fit
- Media Queries
- Responsive Design

## Features
- Sticky navigation bar
- Skincare product cards with badges
- Hero section with floating card
- Promotional discount banner
- Responsive layout for mobile, tablet, and desktop

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

Note: This is a frontend-only project. Product buttons are visual links; cart, checkout, and payment features are not implemented.
