# CineVault — Movie Showcase Website

CineVault is a modern movie and cinema showcase website created using HTML5 and CSS3.

The project focuses on combining previously learned HTML/CSS concepts with some final advanced concepts.

## Technologies Used

- HTML5
- CSS3

## HTML Concepts

- Semantic HTML
- Navigation
- Images
- Links
- Forms
- Labels and inputs
- Video element
- Accessibility basics
- Meta description

## CSS Concepts

- CSS Variables
- Flexbox
- CSS Grid
- Positioning
- `::before` / `::after` concepts
- `:hover`
- `:focus`
- `:checked`
- `:nth-child()`
- CSS Gradients
- `overflow`
- `clamp()`
- Responsive Design
- Media Queries
- CSS Transitions
- CSS Transforms
- `@keyframes` animation
- Image overlays

## Features

- Responsive movie showcase
- Featured movie section
- Movie cards
- Hover effects
- Category navigation
- CSS-only radio button selection
- Video section
- Newsletter form
- Responsive mobile layout
- Animated hero section

## How to Run

1. Open the project folder in VS Code.
2. Make sure these files are present:

   `index.html`
   `style.css`
   `README.md`

3. Open `index.html` using Live Server.

## Note

This is a frontend-only project.

The movie filtering, newsletter submission, and movie actions are currently visual/frontend interactions. JavaScript and backend functionality are not implemented.
