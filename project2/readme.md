# 📚 Concepts Learned

## 1. Adding Images

HTML provides the `<img>` element to display images.

```html
<img src="image.jpg" alt="My Developer Profile" width="200">
```

### Important attributes

| Attribute | Purpose                      |
| --------- | ---------------------------- |
| `src`     | Specifies the image location |
| `alt`     | Provides alternative text    |
| `width`   | Controls image width         |

### Example

```html
<img src="profile.jpg" alt="My Developer Profile">
```

---

## 2. Creating Links

The `<a>` element is used to create hyperlinks.

```html
<a href="https://github.com/srividhyachintada6">
    Visit my GitHub
</a>
```

When the user clicks the text, the browser opens the specified URL.

### Important attribute

`href` → specifies where the link should go.

---

## 3. Relative Path

For an image inside the same project folder:

```html
<img src="profile.jpg">
```

Here:

```text
index.html
profile.jpg
```

are in the same folder.

---

## 4. Absolute URL

For an external website:

```html
<a href="https://github.com/srividhyachintada6">
    Visit my GitHub
</a>
```

The `href` contains the complete website URL.

---

## 5. HTML Attributes

This project helped me understand that HTML elements can have attributes.

Example:

```html
<img src="profile.jpg" alt="My Developer Profile" width="200">
```

Here, `src`, `alt`, and `width` are attributes.
