## 📚 HTML Concepts Learned

### 1. HTML Document Structure

Learned the basic structure of an HTML document:

```html
<!DOCTYPE html>
<html>
<head>
    <title>My Developer Journey</title>
</head>
<body>

</body>
</html>
```

Understanding:

* `<!DOCTYPE html>` — tells the browser that the document uses HTML5.
* `<html>` — root element of the webpage.
* `<head>` — contains information about the webpage.
* `<title>` — sets the browser tab title.
* `<body>` — contains the visible webpage content.

---

### 2. Headings

Used different heading levels to organize the content.

```html
<h1>My Developer Journey</h1>
<h2>A little about my journey</h2>
<h3>Learning Java</h3>
```

Learned that:

* `<h1>` is the main heading.
* `<h2>` is used for major sections.
* `<h3>` is used for subsections.

---

### 3. Paragraphs

Used the `<p>` element to display descriptions.

```html
<p>
    Java is one of the main programming languages I am learning.
</p>
```

Learned how to structure normal text content inside a webpage.

---

### 4. Horizontal Line

Used `<hr>` to visually separate different parts of the page.

```html
<hr>
```

---

### 5. HTML Attributes

Used attributes such as:

```html
<html lang="en">
```

Learned that attributes provide additional information about HTML elements.

---

### 6. Page Title

Used the `<title>` element:

```html
<title>My Developer Journey</title>
```

This changes the name displayed in the browser tab.

---

### 7. Semantic Structure

Started understanding how webpages can be organized into meaningful sections using headings and content.

For example:

```text
Main Heading
    ↓
Introduction
    ↓
Section
    ↓
Description
    ↓
Section
    ↓
Description
```
