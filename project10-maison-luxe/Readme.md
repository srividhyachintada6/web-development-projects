
# Maison Luxe — Furniture & Interior Design Store

A modern furniture storefront homepage featuring elegant interiors, curated furniture products, and a minimalist design.

## Technologies Used
- HTML5
- CSS3

## CSS Concepts Covered
- CSS Grid and Flexbox
- CSS Variables
- Positioning and Z-index
- Image Overlays
- Hover Effects and Transitions
- Transform and Image Scaling
- CSS Gradients
- Media Queries
- Responsive Design

## Features
- Sticky navigation bar
- Furniture collection with product cards
- Hover-to-reveal product links
- Brand story section
- Responsive layout for mobile, tablet, and desktop

## How to Run
1. Download or clone the repository.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.

Note: This is a frontend-only project. Product links are visual navigation links; cart, checkout, and payment functionality are not implemented.
